# Просмотр базы данных на GitHub Pages

Эта папка содержит статическое веб-приложение для просмотра SQLite-файла бота. Оно работает в GitHub Pages: сервер и сборка не нужны.

## Установка в репозиторий `atomyweb`

Скопируйте **содержимое** папки `sait` в корень репозитория `atomyweb` и опубликуйте изменения через GitHub Pages. В корне сайта должны оказаться:

- `index.html`
- `app.js`
- `styles.css`

Откройте опубликованный сайт, нажмите **«Открыть файл базы»** и выберите `bot.sqlite3` на своем устройстве. После этого выберите таблицу, ищите по ее содержимому и переключайте страницы.

## Важно о базе данных и приватности

GitHub Pages — статический хостинг. Он не может напрямую подключаться к `bot.sqlite3`, который хранится на компьютере или сервере с Telegram-ботом, и не запускает Python-код бота.

Приложение открывает файл только в вашем браузере: оно не отправляет файл на сайт и не включает его в репозиторий. **Не публикуйте `bot.sqlite3` или JSON-экспорт базы в GitHub**: там могут находиться Telegram ID, имена пользователей и другие персональные данные.

Чтобы смотреть актуальную базу, возьмите свежую копию `bot.sqlite3` с устройства, где работает бот, и выберите ее на сайте. Если нужна автоматически обновляемая панель с удаленным доступом, потребуется отдельный защищенный backend/API; одного GitHub Pages для этого недостаточно.

Для работы просмотрщик загружает библиотеку SQLite (`sql.js`) и ее WASM-файл с cdnjs. Поэтому при первом открытии нужен доступ к cdnjs. Содержимое выбранной базы при этом не передается cdnjs.
